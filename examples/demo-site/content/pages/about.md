This site is a test fixture for nefantaris-core. It has pages, posts, assets,
and one directive. The repo contains no framework code at all.

## How it works

1. Markdown is parsed with remark.
2. The theme renders the content tree.
3. Every route is prerendered to a real HTML file.

Inline `code`, a blockquote, and an image:

> Content is data. The theme decides what it looks like.
